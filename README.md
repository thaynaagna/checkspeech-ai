# CheckSpeech AI 🎙️

Landing page responsiva desenvolvida para o desafio de Desenvolvedor Front-End.

## 📌 Sobre o projeto

O CheckSpeech AI é uma solução de APIs para conversão de fala em texto e análise de sentimentos a partir de áudios.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ✨ Funcionalidades

- Design responsivo
- Menu de navegação
- Accordion de soluções
- Formulário com validações
- CAPTCHA
- Consentimento LGPD
- Barra de cookies
- Português e inglês
- Menu mobile
