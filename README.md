# CheckSpeech AI 🎙️

Landing page responsiva desenvolvida para o desafio de Desenvolvedor Front-End.

🌐 **[Acessar o projeto](https://thaynaagna.github.io/checkspeech-ai/)**

## 📌 Sobre o projeto

O **CheckSpeech AI** é uma interface web para uma solução de conversão de fala em texto e análise de sentimentos a partir de áudios.

O projeto foi desenvolvido com foco em **experiência do usuário, responsividade, acessibilidade e performance**.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Web Speech API
* Git
* GitHub
* GitHub Pages

## ✨ Funcionalidades

* 🎙️ Conversão de fala em texto
* 🌎 Suporte a múltiplos idiomas
* 📱 Design responsivo
* ☰ Menu mobile

* 📝 Formulário com validação
* 🔐 CAPTCHA
